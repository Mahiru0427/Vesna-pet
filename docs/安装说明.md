# 薇斯纳 Vesna：小白安装教程

**这只桌宠已经在 Codex 桌面软件里安装成功。第一次使用，建议按下面的 Codex 步骤操作。**

下载的是图片素材包，里面没有可以双击启动的 EXE。要让她动起来，需要用 Codex 的 Pets 功能导入。

## 在 Codex 里使用（本项目已验证）

### 第一步：准备 Codex 和 Pets

1. 安装并打开 **Codex 桌面软件**，登录自己的账号。这里说的是独立桌面软件，不是 VS Code 里的 Codex 扩展。
2. 打开 Codex 的 **插件 / Plugins** 页面，搜索 **Pets**，安装并启用它。如果已经安装，就跳过这一步。
3. 如果你的插件页面里找不到 Pets，先不要继续：当前版本或账号可能没有这个入口。下载本项目不能替你开启 Pets 功能。

### 第二步：下载桌宠图片

1. 打开 [项目下载页面](https://github.com/Mahiru0427/Vesna-pet/releases/latest)。
2. 在页面下方的 **Assets**（下载文件）里，点击名字带 **install** 的 ZIP 文件。这是安装包；带 **project** 的大文件是完整制作工程，普通使用者不需要下载它。
3. 下载后，在 ZIP 文件上点右键，选择 **全部解压**。
4. 打开解压出来的 `Vesna-pet` 文件夹，再打开 `assets` 文件夹，找到 **vesna-v2.png**。这是桌宠图片。它看起来是一张排满小人的大图，属于正常情况。

### 第三步：把图片交给 Codex 导入

1. 回到 Codex，新建一个聊天。
2. 点击输入框旁的附件按钮，选择刚才的 **vesna-v2.png**。也可以把这张图片拖到聊天输入框里。
3. 如果输入框支持选择插件，输入 `@` 并选择 **Pets**。
4. 复制下面这段话，和图片一起发送：

> 请用 Pets 插件把我上传的这张图片导入为桌宠，名字叫“薇斯纳 Vesna”。图片和动作已经做好了，请先验证，验证通过后直接导入并选中，不要重新生成图片。完成后帮我显示桌宠。

5. 等 Codex 回复“导入并选中成功”。这是把图片保存到你自己的账号里，不是把文件双击打开。

### 第四步：找到并显示她

如果导入成功却没有出现，在 Codex 的设置里找 **Pets / 桌宠**，刷新列表并选择“薇斯纳 Vesna”。支持的桌面界面可通过 `/pet` 或 **Show pet / 显示桌宠** 显示；具体入口以你安装的版本为准。

## 别的软件能不能用？

| 软件 | 使用情况 |
| --- | --- |
| Codex 桌面软件 + Pets 插件 | 本项目已实际导入、选中成功。推荐按上面的步骤使用。 |
| ChatGPT 网页版 | 官方提供 Pets 上传功能，但需账号/工作区有该入口。本项目提供兼容图片，尚未在另一个账号实测。网页内显示，不会悬浮到 Windows 桌面。 |
| ChatGPT 桌面软件 | 官方有悬浮 Pets 功能；这份素材包的原图导入流程尚未单独验证，不能直接套用 Codex 教程保证成功。 |
| VS Code 里的 Codex 扩展 | 官方说明没有悬浮桌宠入口。 |
| 其他桌宠软件 | 本项目没有做适配，不能保证直接导入；通常需要按该软件要求另做格式转换。 |

因此，不是只有 Codex 能显示宠物，但**本项目当前实测成功的安装路线是 Codex + Pets**。教程不会把其他软件写成已经验证过的兼容方案。

## 如果你用的是 ChatGPT 网页版

根据 [官方 Pets 文档](https://learn.chatgpt.com/docs/pets)，若账号有入口：

1. 打开 ChatGPT 网页版的 **设置 → 个性化 → Pet → Select pet**。
2. 点击 **Upload pet**，上传安装包 `assets` 文件夹里的 **vesna-v1.png**，然后选中它。
3. 网页要求1536×1872的图片，所以这里选 **v1**；Codex 教程用的是 **v2**。v1含九种动作，少了十六方向注视。

如果设置里没有 Pet 或 Upload pet，说明你的账号/工作区暂时没有对应入口；本项目无法替你开启。

## 常见疑问

- **要安装 Python、运行代码吗？** 用桌宠不需要。Python只用于修改、重新制作展示视频。
- **下载以后能直接双击运行吗？** 不能，下载的是图片，按上面的步骤交给 Pets 导入。
- **需要把整个项目发给 Codex 吗？** 不需要，添加 `assets/vesna-v2.png` 这一张图片即可。
- **为什么桌面上移动鼠标，她没一直看过来？** 本机版本没有持续追踪整个桌面的普通鼠标，转头由应用提供的目标位置触发。
- **视频为什么比实际桌宠清楚？** 视频用高清动作帧制作；应用里的桌宠按较小的图片单元显示。
