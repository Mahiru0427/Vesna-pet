# 薇斯纳 Vesna 桌宠安装说明

1. 解压安装包，找到 `assets/vesna-v2.png`。不要截图、压缩或修改尺寸。
2. 打开支持 Pets 插件的 Codex / ChatGPT Work，并安装、启用 Pets。
3. 把 `vesna-v2.png` 添加到聊天，复制发送：

> 用 Pets 导入这张已有的 v2 精灵图，名称为“薇斯纳 Vesna”。先验证图片，验证通过后直接创建并选中；请保留原图，不要重新生成角色或动作。

4. 完成后在应用的 Pets 设置里选择“薇斯纳 Vesna”；如果有 Refresh，先刷新。
5. 支持悬浮桌宠的桌面应用可通过 `/pet` 或 Show pet 显示，具体入口以应用版本为准。

如果应用没有 Pets 插件/工具，不能仅通过下载素材启用。若网页端提供 Upload pet 且只接受1536×1872，使用 `assets/vesna-v1.png`，这个兼容版本含九种动作，不含十六方向注视。

当前本机版本未持续追踪整个 Windows 桌面的普通鼠标，素材不会自行开启这个能力。

完整项目、预览与视频：https://github.com/Mahiru0427/Vesna-pet

官方应用入口说明：https://learn.chatgpt.com/docs/pets
