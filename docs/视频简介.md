标题：把薇斯纳 Vesna 做成了会动的Q版桌宠！白丝小精灵上线啦

简介：
薇斯纳 Vesna 来陪我上班啦～金色卷发、青绿小裙子、晶莹的小翅膀，还有一点透肤感的白丝都安排上了！
这次展示了待机、跑步、挥手、跳跃、失落、等待、思考、检查，还有十六个方向的转头动作。素材和安装说明已经整理到 GitHub，喜欢的话可以下载，把她带回桌面喵～

麻烦三连给我回回血喵，谢谢喵！如果还有想看的动作，也欢迎在评论区告诉我。

下载地址：https://github.com/Mahiru0427/Vesna-pet

安装方法（推荐 Codex 桌面软件）：先在 Codex 里安装 Pets 插件，再下载并解压桌宠安装包。打开里面的 assets 文件夹，把 vesna-v2.png 添加到 Codex 聊天，告诉它：“用 Pets 导入这张图片，名字叫薇斯纳 Vesna，导入后选中并显示，不要重新生成。”一步一步的小白教程已放在 GitHub。普通使用者不用安装 Python，也不用运行代码。

使用范围：本项目已在 Codex 桌面软件 + Pets 插件中安装成功。ChatGPT 网页版若有上传入口，也可使用包内的 v1 图片，但只能在网页里显示；其他桌宠软件未做适配。这不是下载后双击启动的 EXE。当前本机版本不会持续跟随整个桌面的普通鼠标。视频原片无声音，可自行添加音乐。
